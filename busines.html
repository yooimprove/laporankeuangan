Ganti kata sandi tim

Setelah diganti, semua anggota tim di perangkat lain otomatis keluar dan harus masuk lagi dengan kata sandi baru.

Minimal 6 karakter.

Akses tim

Semua data tersimpan di server. Siapa pun yang masuk lewat link ini melihat data yang sama persis, dan setiap perubahan langsung muncul di semua perangkat. Bagikan link dari tombol Share dengan akses Contributor atau Editor, lalu beri tahu kata sandi tim.

Unduh cadangan

Simpan salinan data secara berkala. File backup bisa dipulihkan kapan saja.

Backup lengkap (.json)Member, transaksi, paket, katalog e-book, dan profil. Untuk dipulihkan.
Data member (.csv)Bisa dibuka di Excel atau Google Sheets.
Transaksi keuangan (.csv)Semua pemasukan dan pengeluaran.

Pulihkan atau impor

Pilih file backup .json dari web ini, atau file .csv dari Excel / Google Sheets. Data yang sudah ada tidak dihapus.
